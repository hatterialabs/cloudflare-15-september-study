# Slovník pro články torumata.com (závazný pro redakci)

Pravidla: v článku se nepoužívají interní výrazy z repa (levý sloupec). Používá se výraz ze sloupce „v článku CS" a při prvním výskytu se vysvětlí jednou větou. Zákaz pomlček v textu (dlouhých i krátkých); rozsahy slovem „až". Spojovník uvnitř slova je v pořádku.

| interní (repo) | v článku CS | v článku EN | vysvětlení při prvním výskytu |
|---|---|---|---|
| hrana | síť Cloudflare | Cloudflare's network | servery Cloudflare, přes které web běží; rozhodují, kdo se na web dostane |
| deklarace (v robots.txt) | pravidla v souboru robots.txt | rules in the robots.txt file | soubor, ve kterém web říká robotům, co smějí |
| vynucování na hraně | odmítání přímo v síti Cloudflare | refusal by Cloudflare's network | web sám nic nedělá, žádost zastaví Cloudflare |
| neověřený žadatel | program, který si jméno robota jen nastaví | a program that merely sets a crawler's name | nejde o skutečného robota firmy OpenAI nebo Anthropic |
| napodobené jméno / UA | jméno robota v hlavičce žádosti | the crawler name in the request header | |
| tréninkový robot | robot sbírající data pro trénink AI | training crawler | např. GPTBot, ClaudeBot |
| agent / agentní identita | asistent, který čte web na pokyn uživatele | user-directed assistant | např. ChatGPT-User |
